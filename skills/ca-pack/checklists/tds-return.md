# Checklist: TDS quarterly return (24Q / 26Q / 27Q)

Job opens 20 days before due. Deposits are a separate monthly job.

1. [ ] Payment and deduction register for the quarter received (proof: file in `sources/`)
2. [ ] Every deductee PAN present and valid; higher-rate cases flagged (proof: PAN check table)
3. [ ] Section and rate applied per payment type checked against `concepts/law/` rate page for the FY (proof: rate check with law page link and date)
4. [ ] Threshold and exemption certificates (lower deduction, 15G/15H) on file where relied upon (proof: certificate references)
5. [ ] Challans matched to deductions: amount, date, BSR, serial (proof: challan match table, unmatched listed)
6. [ ] Interest for late deduction or late deposit computed (proof: computation or "none")
7. [ ] Return file validated with the department's utility, errors cleared (proof: validation log reference)
8. [ ] ◆ Reviewer says yes (proof: timeline)
9. [ ] ◆ Filed by a person · token or acknowledgement number recorded (proof: client timeline)
10. [ ] Certificates (16/16A) generation job opened with its due date (proof: new job page link)
11. [ ] Lessons written if anything changed
