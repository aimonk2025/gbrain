# Checklist: Income-tax return

Job opens 45 days before due (30 for audit cases).

1. [ ] Form 26AS, AIS and TIS downloaded for the year and stored (proof: `sources/` entries)
2. [ ] Books or statements received; for individuals, all income sources listed with the client's confirmation (proof: source list with dates)
3. [ ] AIS vs books reconciliation: every AIS line explained or queried (proof: reconciliation table, open items queried via template)
4. [ ] TDS and TCS credits claimed agree to 26AS (proof: tie-out)
5. [ ] Deductions and exemptions supported by documents on file (proof: document references)
6. [ ] Capital gains computed with cost records and dates (proof: computation sheet in `sources/`)
7. [ ] Firm positions applied where the return takes a stand, each linked (proof: position links)
8. [ ] Correct form chosen with reason (proof: one line on the job page)
9. [ ] Tax, interest (234A/B/C) and fee computed; advance tax and self-assessment challans matched (proof: computation)
10. [ ] Draft computation sent to the client for confirmation via template (proof: sent and reply dates)
11. [ ] ◆ Reviewer says yes (proof: timeline)
12. [ ] ◆ Filed by a person · acknowledgement number recorded; e-verification done or deadline set as a task (proof: client timeline, task link)
13. [ ] Lessons written if anything changed
