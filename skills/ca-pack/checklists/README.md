# Checklists

Pack defaults. The firm's edited copies live in the brain under
`concepts/checklists/<service>` and win when they exist. A job page copies the
checklist at open time, so a later edit changes future jobs, not open ones.

Each line is a verifiable step. "Verified" means the proof named in brackets
exists and is linked from the job page. Claude never ticks a step without it.
