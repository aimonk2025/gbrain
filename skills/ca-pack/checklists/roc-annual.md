# Checklist: ROC annual filings (companies and LLPs)

Job opens 20 days before due. Due dates depend on the AGM date for companies.

1. [ ] AGM date recorded on the client page with source (proof: timeline entry)
2. [ ] Financial statements adopted at the AGM, signed copies on file (proof: `sources/`)
3. [ ] Board report, auditor's report and notes complete (proof: document references)
4. [ ] AOC-4 (or AOC-4 XBRL where applicable) prepared and pre-scrutiny passed (proof: utility log)
5. [ ] MGT-7 / MGT-7A: shareholding, directors, meetings, charges checked against registers (proof: register tie-out)
6. [ ] DIR-3 KYC status checked for every director; tasks opened for pending ones (proof: task links)
7. [ ] DSC validity and custody confirmed for signatories; the brain records who holds it and till when, never the PIN (proof: client page docs line)
8. [ ] Fees and additional fees computed if late (proof: computation)
9. [ ] ◆ Reviewer says yes (proof: timeline)
10. [ ] ◆ Filed by a person · SRN recorded on client timeline (proof: SRN, date)
11. [ ] Lessons written if anything changed
